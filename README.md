# Little Word Coach

A playful, phone-friendly app for listening to words and practicing spelling.

## Run locally

Install Node.js (20.19+ or 22.12+), then run:

```sh
npm install
npm run dev
```

Open the address printed by Vite in a browser. To create a production build, run `npm run build`; `npm run preview` serves that build locally.

Choose a word, tap **Hear the word** to listen, then tap the letters in order. Take a letter back or start again whenever you like. Speech uses the browser's built-in text-to-speech and may not be available on every device or browser. The app does not listen to or grade pronunciation.
