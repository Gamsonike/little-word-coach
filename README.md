# Little Word Coach

A playful, phone-friendly spelling and pronunciation app for young learners.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

The app uses the browser's built-in speech synthesis for word pronunciation. Audio controls show a notice when speech synthesis isn't supported.

## Practice flow

Listen to a word, type its spelling, and check your answer. Hints reveal the first letter. The eight-word practice set, progress, and score are managed in the browser and reset when you start a new adventure.
